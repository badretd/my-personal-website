1. Core idea

The website combines a conventional personal-site structure with an unconventional procedural first screen.

The header should make the site understandable.

The background should make it recognizable.

The contrast between a familiar menu and a continuously recomposed visual environment is central to the project.

2. Desired feeling

The website should feel:

dark;
composed;
cinematic;
editorial;
precise;
procedural;
restrained;
slightly absurd;
slightly unsettling;
technically deliberate.

It should feel like a sequence of short station identifications, film fragments, broadcast bumpers, generative posters, or title sequences.

It must not feel chaotic.

3. Identity

Primary identity text:

[ badretd ]

The identity should be treated as typography, not as an illustrated logo.

It should normally remain compact.

Do not enlarge it into a conventional oversized hero logo.

Interstitial identity:

[ badretded ]

This is a separate intentional text shown only during scene transitions.

4. Composition

Use:

negative space;
grid-based positioning;
controlled asymmetry;
strong empty regions;
cropped systems;
elements continuing beyond the viewport;
clear focal areas;
visible structure;
restrained typography;
hard editorial cuts.

Every scene should look intentionally arranged even though its configuration is generated.

Randomness must operate inside design constraints.

5. Header

The header is the stable layer of the website.

It should:

remain readable;
remain in a consistent location;
remain independent of the generated grid;
use compact typography;
avoid excessive visual weight;
provide clear route access;
work with keyboard and touch input.

The header must not look like a floating SaaS navigation pill.

Avoid:

a large rounded container;
excessive backdrop blur;
a glowing outline;
an oversized call-to-action button;
a large animated hamburger icon. 6. Hero typography

The hero contains:

one short title;
one short descriptive line.

The title may be expressive but should not become a giant landing-page headline.

Attention should come from:

placement;
surrounding empty space;
contrast;
relation to the generated systems;
timing;
framing.

The descriptive line should remain readable and secondary.

7. About typography

The About preview should be quieter and more stable than the hero.

It should feel like the viewer has left the generated title sequence and entered readable editorial content.

Possible hierarchy:

small contextual subtitle;
medium section title;
readable body copy;
compact text link or button.

Do not put the entire About section inside a glowing card.

8. Color

The base environment is dark but should not rely exclusively on pure black.

Suggested foundation:

primary background: near-black;
transition background: dark warm gray such as #11110f;
primary text: warm off-white;
secondary text: muted gray;
scene accents: limited per scene.

Each generated scene should use a restrained palette.

A scene should normally contain:

one background color;
one primary foreground color;
zero to two accent colors.

Do not generate unrestricted random RGB colors.

Use curated palette collections.

Avoid default purple-blue gradients.

9. Motion

Motion should resemble:

machinery;
broadcast graphics;
measured systems;
diagrams;
scanners;
fields;
waves;
modular structures;
controlled image processing.

Motion should not resemble:

confetti;
app onboarding;
playful bouncing UI;
generic parallax;
a video-game menu;
a screensaver made from arbitrary particles.

The transition to the interstitial is an editorial cut.

It should not feel like the site is loading.

10. Texture

Texture may be created through:

subtle grain;
restrained dithering;
line density;
repeated modular shapes;
masks;
low-contrast noise;
controlled raster-like patterns.

Do not apply an aggressive global VHS filter.

Do not make text difficult to read for the sake of texture.

11. Borders and radii

Prefer:

straight lines;
rectangular regions;
square corners;
subtle separators;
grid boundaries used only when compositionally useful.

Avoid excessive:

rounded cards;
circular badges;
pills;
soft floating containers.

Rounded corners may be used only when they belong to a specific visual system.

12. Forbidden default patterns

Do not use:

glassmorphism;
gradient blobs;
floating glowing spheres;
a card grid for every section;
fake browser windows;
fake code editors;
fake terminals used as decoration;
generic monospace code snippets;
huge centered hero copy;
abstract particles without structural purpose;
global neon glow;
cyberpunk clichés;
a rotating 3D object added only for visual impact;
excessive scroll effects;
cursor-following decoration;
an animated custom cursor;
endless marquee text;
random technical words in the background;
invented interface metrics. 13. Responsive interpretation

Mobile is not a scaled desktop version.

Mobile should have:

fewer simultaneous systems;
larger safe areas;
simpler motion;
clear typography;
stable navigation;
deliberate cropping;
no horizontal overflow.

Preserve the idea of procedural recomposition, not every desktop detail.
